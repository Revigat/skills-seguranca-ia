# Advanced

This folder is for people who already work in security, in a lab, a competition, or an authorized system. It is not the first step for someone who only wants to check a skill before installing it. For that, use `review-skill-before-installing`.

1) `cybersecurity-skills-mukul975` was written by Mahipal (GitHub mukul975). It was not made by Anthropic. The author's own README says so. This copy has 173 skills. The other 645 stay in the original repository. See the `NOTICE` in that folder.
2) `ctf-skills` was written by Lukasz Jagiello. It describes competition (CTF) techniques. Do not run `scripts/install_ctf_tools.sh` until you have read the whole file.

Use only on a system you own or have written permission to test.
